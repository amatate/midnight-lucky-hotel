# 路线收益与代价修正 · 2026-09-07

## 范围与结论

以个人游玩乐趣为目标：保留成型后的正收益机器，修正“升级反而拖垮自己的引擎”、成长断点和无限免费转。没有更改基础赔率、房间目标、存档历史成绩或付费整备规则。

旧规则：rules-705e0a792a2c3847；本次规则：rules-54eb1749df08ea12。
实现目录：`.worktrees/slot-machine-prototype`。当前工作树还有此前的修改，本轮未提交或推送。

## 为什么祝福只收一次、一共一个空白

第一稿仅把每次三轮污染改为班内临时污染，仍未解决高密度多线7的负收益：
定向测试中，12格全7、殉道者L2、24个种子、每种子3次付费转，
无祝福平均付1575元，装第一稿祝福L1反而只有1407.29元（下注10元）。

最终限定为整班只加1个空白。对上述全7机器、无食物或其他效果：
- 无祝福：3 × 5 × 3.5B × 3 = 157.5B。
- 祝福L1：第一转56B，之后每转期望52.5 × 12/13 + 3.5 = 51.962B，合计159.923B。
- 这是该特定成型机器的期望推导，不是保证每一盘或任意构筑都赚更多。

脚本：`node scripts/audit-routes.ts`。
10个合成构筑，每构筑24个固定种子，连续4个真实“三次付费转”班次，包含自动免费转；不用干预、买餐和新升级，殉道者样本按规则献祭并计入费用。每班最多观察24转，超限明确记为截断，不冒充完成班次。

下表为4班的平均每班净收入，单位B=10元；不是RTP或房间通关率。

| 再装祝福 L2 | 3.602 | 5.990 |

| 初始轮 + 压榨机 L1 | -0.383 | 0.096 |
| 纯柠檬 + 感染 L2 | 10.500 | 25.500 |
| 分轮纯图案 + 沙拉/酱 L2 | 72.000 | 72.000 |
| 纯樱桃 + 果酱/压榨机 L2 | 93.000 | 93.000 |
| 裂纹混合轮 + 磁铁 L1 | -1.253 | -0.857 |
| 纯空白 + 电容 L2 | 不比较（存在未收班截断） | -3.000 |

- 新版所有样本的所有班次均在观察上限内结束；纯空白电容每班正好3付费+3免费。
- 旧版祝福+电容第一班仅17/24个样本在24转内完成；不能拿其19.437B窗口收入与新版完整班次收入直接比较。
- 新版成熟纯柠檬L2感染每班赔付28.5B、净25.5B；单靠它不能自动过36B顶层目标，仍需厨房等配合。
- 沙拉与樱桃的极端成型上限未砍。它们明显高于单部件柠檬，但也要求不同的图案分布与两个L2部件；本轮没有据此宣称成长时间等价或全路线平衡。
- 磁铁单独挂机仍为负收益。故障线尚需围绕踹击预览、保修赔付、损伤控制进行真人测试，而不是继续盲目抬高倍率。
