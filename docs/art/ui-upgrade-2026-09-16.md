# 机台美术升级 · 2026-09-16

本轮目标：把手机里的网页面板改造成一台可以触摸、改造、结算的酒店老虎机。延续得意黑斜体、Barlow Condensed 数字、原有水果图案和淡金 Art Deco，不改变玩法、概率或存档。

## 视觉约定

- 墨绿烤漆 `#0c1715`、浅香槟金 `#c3a76b`、象牙珐琅 `#f2e3c0`、到账暖金 `#edcf87`、拉杆暗红 `#a63243`。
- 唯一主视觉是有实体边框的机器：金额玻璃窗 → 三列转轮与红拉杆 → 部件凹槽 → 主操作键。
- 320px 起单列、可滚动，不把屏幕强制锁死；桌面把准备操作放到机台右侧，主机不横向拉伸。
- 前台使用生成的酒店场景，把继续／开局作为主动作，种子设置和存档详情收在可展开区。

## 本轮实现

- `public/art/cabinet-frame-v1.png`：通过 CSS 九宫切片使用，固定顶冠和金属侧轨的视觉尺寸，中段可随内容伸长。
- `public/art/hotel-lobby-v1.png`：前台背景及桌面环境。文字、金额和按钮均不烘焙在图里。
- 主机玻璃读数窗、曲面珐琅转轮、金属嵌框、红色球柄、部件插槽、实体主按钮；保留原来的动画与输入控制器。
- 停轮后的干预和结算都留在机台内部，减少阅读外部报表的感觉。服务选项使用钥匙牌式标识；升级卡与主机材质保持一致。
- 两张图片加入 PWA 预缓存。图片不可用时仍有颜色与边框回退，操作不依赖图片加载。
- 完整原图提示词、内置图像生成来源与尺寸见 `ui-art-prompts.md`。

## 不变的边界

1. 演出只呈现规则引擎已经产生的事件，不重新计算结果；奖金额逐步公开。
2. 九宫格固定窗口高度，滚动填充层不能决定父级尺寸，也不能提前露出真实结果。
3. 拉杆和按钮共用一个控制器；一次手势只发出一次转动命令。
4. 随机重转不展示未来盘面；踹击预览取消后不改钱、随机数或存档。
5. 保留原有本地存档、日志、种子、旧规则迁移、弱动画和帮助暂停行为；不推送、不自动发布。

## 有限验证范围

浏览器使用独立上下文和测试档，覆盖手机窄屏／常见手机／桌面、转动中的九格窗口、真实触摸拉杆、取消和确认干预、主菜单、机台内结算与基础文字对比度。新增断言防止新图框继承旧铭牌偏移。自动检查不能代替实际手机触觉、网络速度和长时间游玩的判断。
