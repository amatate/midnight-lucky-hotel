# 花园房回合原型 · 2026-09-26

范围：只扩展花园房，其他房间保持单回合；不改下注、核心赔率和部件数值。

## 规则

- 3 回合 × 3 次付费转，每转 25；全房累计毛奖金目标暂定 1000。免费转计奖不占名额，清空队列后换回合。
- 第 1、2 回合后各一次免费三选一，确认或放弃直接换回合。前两回合不按分数淘汰；资金耗尽仍失败。
- 入房只检查首回合 75 备付金。新回合恢复干预点、服务使用次数和班内标记；永久符号、部件、跨班蓄能和剩余餐效保留。
- 同局每个休息点仅赠一次免费强化。失败保留构筑和奖金，重试清空房间累计分；已领休息点不重复赠送。金币整备仍限整房结束后一次。
- 不改历史结果：旧 Garden 挑战没有 rounds 字段，继续用单回合及历史目标。旧规则档案通过明确的“新版续玩”生成分支，原档不覆盖。
- 1000 是首版待试玩值（总下注的 4.44 倍），不是已证明的最优平衡。验证对象是中途选择能否改变后续体验，不追求所有路线同胜率。
