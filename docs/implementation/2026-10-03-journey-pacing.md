# 三房成长流程：第一阶段试玩版

## 范围

先打通成长节奏，不同时增加部件、Jackpot、永久成长或新的资源。音画、赔率、五个部件槽与 L2 上限保持原样；第三房干预上限从 2 放宽至 3，避免增长目标、改变流程与压缩操作空间同时发生。

| 阶段 | 次数 | 目标 | 免费强化 |
| --- | --- | --- | --- |
| 新局开场 | 3 班 × 3 转 | 余额 ¥150，起始 ¥100 | 前两班各一次 |
| 花园房 | 3 回合 × 3 转 | 累计毛奖金 ¥1000 | 前两回合各一次 |
| 景观房 | 3 回合 × 3 转 | 累计毛奖金 ¥2400 | 前两回合各一次 |
| 顶层套房 | 3 回合 × 3 转 | 累计毛奖金 ¥6000 | 前两回合各一次 |

后三间仍为原有单回合特殊挑战，本阶段未统一重做。以上目标是试玩参数，不是模拟得出的最佳平衡。

## 流程与约束

- 中场不按累计奖金淘汰；第三回合及其免费转队列结束才判通关。提前达标不截断剩余回合。
- 中场选强化后直接开始下一回合，恢复干预点及服务次数；永久改造、部件、跨回合蓄能和剩余餐效保留。班内计数仍按原规则重置。
- 每房的两个休息点分别计领，同局重试不再赠送。失败仍可付费整备、重试或回自由加班；没有新增重试次数限制。
- 入房只要求首回合下注储备，不额外扣门票；余额不足下注仍会失败。免费转计入奖金但不占付费次数。
- 保持结算先确定、演出后展示；不提前泄露待播放奖金，不让语言或音效改变随机序列。

## 存档

- 新局标记 `introShifts: 3`，目标 ¥150；无此标记的历史局保留五班、¥200。不自动把玩家送到新进度。
- `gardenRewardsGranted` 保留；新增 `roomRewardsGranted` 分别记录第二、第三房领取次数。不能让花园房奖励计数挡住后续房间，也不能在重试中清零。
- 已发布版本 `rules-b5bc23b088249f53` 可显式创建新版续玩分支，保留原档、钱包、进行中转动及客房目标。当前单回合打完，再次入房才采用三回合。
- 修复完成客房迁移时只保留 `cleared/challenge` 而丢失领奖历史的风险：保留完整酒店进度对象。
- 历史五班测试使用明确的 `createLegacyRun`，新流程单独覆盖；并非把旧期望直接全改成三班。

- 全量 815 项检查中 814 项通过，剩余一项是旧界面文案断言；更新后，新流程、该界面和双语共 30 项定向复测通过。类型检查和生产构建通过。

- 未重新跑大规模平衡模拟，未推送 GitHub 或部署 Pages。
