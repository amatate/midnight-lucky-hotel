# 固定手机机台 · 第一版

日期：2026-09-26。依据：用户确认的固定机台方案与得意黑字体样张。本记录完成时仅本地实现；后续发布准备见 [GitHub Pages 发布记录](2026-09-26-github-pages.md)。

## 已落地

- `GameScreen` 使用固定仪表 / 奖金窗 / 九格与列键 / 五槽 / 操作台。正常循环不增加页面高度，四个阶段不挪动盘面或部件。手机优先，桌面居中最大宽 430px；短屏与放大字体允许纵向回流，不禁止缩放。
- 保留原机台、房间顶冠、部件图集、原水果图案及右侧拉杆。主键、三列实体键和短铭牌统一得意黑，数字保留 Barlow，正文使用系统中文字体。
- 点餐先选轮，盘面或实体列键均可选；确认才付钱。其他准备、调注、精修进入准备抽屉；祈祷使用符号按键。选择 / 取消不发送规则命令。
- 干预模式与预览说明在底部固定区域；随机重转不预测结果，踹击仍使用真实确定性预览。当前线可能被打散的风险保持可见；金额 / 干预点 / 永久裂纹费用列于确认键。
- 奖金在上方同一窗口按原事件序列累加；下方只展示当前因果说明和加速 / 跳过。结算自动返回准备，不新增“下一步”。首次发现改为轻提示，详细解释可展开。
- 菜单收纳玩法、日志、导出、备份、种子、已获升级、减少动态；账本保持直接入口。说明 / 账本 / 菜单暂停自动停轮和结算；多层抽屉使用计数式暂停，关闭内层不会提前恢复。
- 班后三张短维修票；选择后弹出独立确认抽屉，保留目标选择、替换部件、即时费用及后果预览。小票单独查看，不占据整页顶部。
- 修复深底部件说明的黑字；按钮保留成对前景 / 背景、触摸 hover 和键盘焦点状态。拉动主键要求当前可用阶段的新按下事件，防止上一阶段松手被算成下一次下注。

## 不变边界

不改规则、赔率、候选池、房间目标、费用、随机数、存档结构及素材映射。五槽支持真实跨路线混搭；储量、奖金和部件损坏继续按演出序列公开。

## 有限验证

- `npm run build`：通过。仍提示主 JS chunk 超过 500kB，未在本次做不相关拆包。
- 8 个受影响组件测试文件、84 项：通过（移动机台、干预、帮助、发现、演出、拉杆、账本、升级）。包含多层说明暂停、账本暂停、迟到 pointer-up 不下注。
- `npx playwright test --config playwright.console.config.ts`：3 项通过。独立 Chromium / 存档，未读取或修改玩家浏览器数据。
- 手机 360×640、390×760、430×932：准备 / 转动 / 干预 / 结算均检查；9 窗、5 槽、零横向溢出、普通字号不滚动；盘面与部件 y 坐标不随阶段改变。
- 从前台种子 8 开新局，选择厨房，完成 3 次付费转和一次真实升级，回到下一班；另检查 1280px 桌面居中与 125% 字号纵向回流。
- 定向验证送餐选列和取消零消耗，确认恰好花 ¥37.5 一次；说明正文 computed color 为 `rgb(242, 227, 192)`，肉眼复核实际截图。
