# 经典机台 · 独立基础模式

目标：先验证一台没有构筑和关卡干扰的精致老虎机，主要观察转动、刹停、拉杆和派奖是否令人愿意再玩。保留酒店 Roguelite，暂不发布线上。

## 技术和视觉选择

- React 保留为可访问的外壳、数字表、按钮与弹窗；Three.js 0.186.1 只处理三个有实际曲面的转鼓，不把手机端改成自由移动的 3D 场景。
- 淡金 `#d8c48f`、象牙 `#f2e3c0`、墨绿 `#0c1715`、搪瓷绿 `#1d392c`，酒红拉杆。沿用 Smiley Sans 机台字与 Barlow Condensed 数字，正文优先可读。
- 匀速段、减速段、错峰停轮和轻微归位；声音、灯光、跳奖与金币分级。回本不作盈利庆祝，不制造虚假的近失大奖。
- 渲染与规则完全分离；RNG 停点决定动画终点，不由动画帧率或玩家松手时间决定中奖。
- 懒加载 3D 模块，像素密度上限 1.75，停转时不持续渲染，后台暂停绘制；失去 WebGL 上下文降级到 DOM 转轮。减少动态保留相同结算但去掉连续转动与飞散金币。

## 单线赔付

仅中间横线计奖，三列各有 20 个等概率停点。每列含樱桃 4、柠檬 5、BAR 4、铃铛 3、红 7 为 1、空格 3；各列顺序不同。

| 中央结果 | 毛赔付 / 下注 |
| --- | ---: |
| 红 7 × 3 | 150 |
| 铃铛 × 3 | 25 |
| BAR × 3 | 12 |
| 柠檬 × 3 | 8 |
| 樱桃 × 3 | 5 |
| 任意位置 2 个樱桃 | 2 |
| 任意位置 1 个樱桃 | 1（回本） |
| 其他 | 0 |

只取一档，不叠加。可选下注 5 / 10 / 25 / 50。

穷举 8,000 个组合：理论 RTP 94.0125%，有赔付 51.5125%（含 38.4% 回本），净盈利 13.1125%，三红 7 为 1/8,000。下注档位不改变概率。理论平均净消耗是每转下注的 5.9875%，短局方差很大。

这版有意保留机械老虎机偏频繁的小回馈和稀有大额命中，先评估基础手感；不据此断言它比构筑模式更好玩，也不把「无限爽玩」作为固定负期望机台的承诺。

## 数据边界

- `src/classic/engine.ts`：不可变规则、种子随机、赔付与会计恒等式。复用原 RNG 函数但使用独立随机状态，不改 `src/core` / `src/content`。
- `src/classic/storage.ts`：独立键 `midnight-lucky-hotel.classic.v1`，不读写酒店存档。
- 操作顺序：在本地存储同时预扣下注、保存结果 → 播放动画 → 结算结果。未播完关闭的结果在再次进入时补结算一次。
- 保留最近 80 转明细，累计总下注和总赔付不截断。当前筹码 = 1,000 − 总下注 + 总赔付 − 待结算下注。
- 写入前比较原始版本，现代浏览器另用 Web Locks 串行处理多标签操作。陈旧标签停止操作并提示重载；不支持 Web Locks 时仅有冲突检测，不保证跨进程同时写入的原子性。
- 存档损坏或存储不可写时不默默重置。重新开台必须确认，只清除经典模式。经典账本暂不提供云同步或导入导出；酒店的导入导出不包含经典记录。
- 语言、声音、减少动态是共享偏好。入口 `?mode=classic&lang=zh` / `en`。直接打开经典模式不会初始化酒店档案。

## 验证范围

规则测试涵盖完整组合穷举、各档赔付、存档拒绝、重复点击、重开恢复、会计守恒、账本截断与最终停点。浏览器检查使用独立测试会话，不使用个人浏览器存档。

本轮针对性检查：8 个文件共 42 项通过（经典规则、界面和入口，原 App、语言、档案界面与声音回归）。未重跑所有历史测试，不将这些结果描述为全量回归。

浏览器独立会话检查：390×844、390×700、320×640 手机窗口及 1280×900 桌面；实拖拉杆、转中截图、三 BAR 真实种子 44（下注 10 / 赔付 120 / 余额 1,110）、转中刷新及再次刷新、主动 WebGL 上下文丢失后的 2D 降级。320px 页面没有横向溢出；矮屏允许少量纵向滚动，不缩小触摸区域。

根路径与 Pages 子路径构建通过；英文生产预览实际加载 3D 和字体，直接经典入口只创建经典存储键。酒店规则指纹仍是 `rules-a3d7519aafedd7f5`。Three.js 为单独懒加载块，约 530 kB / gzip 132 kB；仍有构建的大块提示，未以忽略警告冒充优化。生产依赖审计没有已知漏洞；安装时出现的开发工具链告警未在本任务中批量升级。

3D 是程序化转鼓与光照，不是完整高精模型、真实刚体物理或经过认证的赌场 RNG；真实 iPhone GPU/触感仍需要设备试玩反馈。复用现有音乐和音效，增加跟随逐轮停转收尾的合成机械底噪；实际音色偏好仍需试听，后续再决定是否换录制素材。
