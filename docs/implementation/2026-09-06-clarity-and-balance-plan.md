# 说明浮窗与数值体验：小步迭代

1. 统一手机可点击、键盘可关闭的说明浮窗。行动旁展示消耗、效果、限制和当前状态；专注、裂纹、小费等资源可直接查说明。打开说明时暂停自动推进，不消耗游戏资源，不读取未来随机结果。
2. 游戏介绍承接基础规则、各路线目标、术语、班次重置与统计限制。保留当前机器 UI、拉杆/结算手感和已有图鉴；不增加强制确认点击。
3. 数学模型：基础连线期望用精确公式核对；成型/成长中的合成构筑以同一组 64 个种子模拟真实指令，每样本最多 12 转，统计三付费转收益、分位数、零赔付率、房间达标率和截断率。分别比较餐费、献祭、L1/L2 与故障启动。模型不冒充真实玩家通关率。
4. 用基线决定有限调整：解除故障收益部件的自锁、控制持续叠加的上界、服务成本随局内下注尺度变化、公开客房目标；不按玩家收入动态调难度。每项改动记录数学依据与副作用。
5. 定向验证新规则、说明浮窗的暂停/键盘行为、存档规则隔离，构建与一次隔离手机浏览器冒烟。既有未提交修改全部保留；不推送或更改玩家存档。

目标不是所有路线收入完全一致：保留柠檬稳定成型、樱桃班内成长、沙拉混合组合、小教堂爆发、故障回收的差异。最终爽感和难度仍需真人试玩。

五项均已实施：独立只读浮窗／共享游戏介绍／精确基础枚举与小样本模型／公开数值校准／定向验证。
