# 构筑组件 × 六房机型 · 本地实现

版本：`playtest-2026.09.24-room-cabinets`。用户批准概念方向后实施；未推送、未部署线上。开发服务位于 http://localhost:5173/ 。

## 已交付

- 19 个部件和 1 个餐罩的实体图集；五槽按真实安装顺序显示，支持跨路线混搭，不按服务强行替换整套皮肤。空槽仍为空槽，图片失败保留文字与旧图标。
- 六个房间独立的顶冠、机身材质、边轨和房间背景；普通酒店机台仍用既有皮肤。
- 累计目标用奖金条、留声机房用峰值指针、双星阁用三盏达标灯；付费转次数读真实房间配置，免费转不消耗刻度。
- 果桶、烛台、电容的读数，以及飞轮保护强度可直接查看。结算中隐藏提前提交的储量，以“结算中”占位；贡献与失效仍按已播放事件序列揭示。
- 准备操作移入机台下半部，点餐/点烛仍是明确的花费按钮；点部件只打开只读帮助。固定下注不再出现三个不可点选项，费用和具体规则保留浮窗。
- 保留淡金、原有字体、水果图案、固定九宫格与红色拉杆。桌面是窄机台 + 工具侧栏；320px 手机无横向溢出。多准备操作混搭时仍需纵向滚动，没有以裁切内容强塞一屏。

## 实现入口

- `src/app/components/CabinetArtwork.tsx`：静态图集、单元与顶冠裁切、加载失败回退。
- `src/app/components/PartReadout.tsx`：真实部件读数、结算防剧透。
- `src/app/components/RoomGoalInstrument.tsx`：只消费已呈现进度的目标仪表。
- `src/app/cabinet-builds.css`：房间材质、五槽装配架、准备台和响应式。
- `GameScreen` / `PartsBar` / `Hud` / `ActionBar`：接入现有状态和控制器；`HelpButton` 增加显式可访问名称。
- `vite.config.ts`：新版本标识、图集加入离线预缓存。规则指纹机制未变。

素材和完整生成提示词：[生产素材记录](../art/room-cabinet-assets-2026-09-24.md)。顶冠透明光晕用原生 SVG 轮廓裁切；图集显示都额外限制单元边界，避免宽插槽露出邻近图块。没有把概念图的文字、数字或按钮当真实 UI。
