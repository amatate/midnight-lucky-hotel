# 第三阶段：让资源有用，让成型构筑有去处

范围：本地可玩版本；不做商业化、云存档或大规模平衡仿真。

1. 厨房 ¥10 点餐立即获得接下来 3 转 +50% 赔付；仍向指定轮加入食物，抽中后额外获得之后 3 转 +25%。免费转也消耗持续次数，所有加成相加后只乘一次。
2. 每段第一转前，3 枚小费可把指定已装备 L1 部件升到 L2；不占三选一、不重抽随机数。原有刷新、维修用途保留。
3. 新部件：樱桃压榨机（第一条樱桃中奖线，盘面超出 3 颗的字面樱桃每颗加 0.5 / 1 倍下注）；沙拉酱（每条水果沙拉额外加 50% / 100% 原始奖金）。保持柠檬永久感染规则。
4. 五班通关后分流：自由加班保留原规则；升房挑战每房 3 次付费转及其免费转，只计算本段赔付，旧余额不抵目标。花园房 ¥25 / 目标 ¥450 / 专注上限 3；景观房 ¥50 / ¥1500 / 上限 2；顶层套房 ¥100 / ¥5000 / 上限 1。固定下注不可切档，目标不会读取历史收入调整。通关得一次常规三选一；失败无升级，可原房重试、回自由加班或结账；中途破产仍失败。房间不扣目标金额，不额外收门票。
5. UI 同步食物倍率、小费升级、客房预告和结果；日志记录命令、事件与客房状态，图鉴加入新部件。

约束：复用确定性指令/结算系统；不由 UI 计算奖金；旧 schema 2 档案允许缺省 hotel 扩展，不改写旧内容与版本。新规则指纹隔离旧局（可查看、导出，不可直接续玩）。保留所有现有未提交修改。

验证：定向测试点餐、部件升级/奖金、三房边界与失败/重试、存档重放；一次构建和一个隔离浏览器冒烟。自动化不证明好玩，数值为第一版试玩值。
